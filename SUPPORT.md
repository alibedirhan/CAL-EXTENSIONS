# Support

Sorun yaşamadan önce şu komutları çalıştır:

```bash
gnome-shell --version
gnome-extensions info ubuntu-desktop-tools@cal
bash scripts/status_extension.sh
bash scripts/diagnose_install.sh
```

Issue açarken şunları ekle:

- Ubuntu / Linux dağıtımı
- GNOME Shell sürümü
- Wayland mı X11 mi?
- Eklenti sürümü veya commit hash
- Kurulum yöntemi
- Hata ekran görüntüsü
- Log çıktısı

Acil kapatma:

```bash
bash scripts/emergency_disable.sh
```
