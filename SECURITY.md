# Security Policy

## Supported versions

Public stable release oluşana kadar yalnızca en güncel ana branch için güvenlik düzeltmesi hedeflenir.

## Reporting a vulnerability

Güvenlik açığı bulursan lütfen public issue içinde exploit detayı paylaşma.

Şunları bildir:

- Eklenti sürümü / commit hash
- GNOME Shell sürümü
- Dağıtım ve oturum tipi
- Açığın kısa açıklaması
- Tekrarlama adımları
- Varsa log çıktısı

## Security principles

- Eklenti API anahtarı veya gizli token içermemeli.
- Riskli terminal komutları engellenmeli.
- Kullanıcı notları yerelde kalmalı.
- Hava durumu dışında dış servise veri gönderilmemeli.
- Dış servise gönderilen veri README’de açıkça anlatılmalı.
